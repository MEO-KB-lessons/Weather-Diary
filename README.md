# Weather Diary - Дневник погоды

## Автор
**Иван Петров**

## Описание программы
Weather Diary - это графическое приложение для ведения дневника погоды. 
Программа позволяет:
- Добавлять записи о погоде с указанием даты, температуры, описания и наличия осадков
- Просматривать все записи в удобной таблице
- Фильтровать записи по дате или по температуре (выше заданного значения)
- Сохранять данные в JSON файл и загружать их при запуске
- Проверять корректность вводимых данных

## Установка и запуск

### Требования
- Python 3.6 или выше
- Библиотека tkinter (обычно входит в стандартную поставку Python)

### Запуск приложения
1. Скачайте файл `weather_diary.py`
2. Откройте терминал/командную строку в папке с файлом
3. Выполните команду:
```bash
python weather_diary.py
